# Knob — panda MIDI keypad

Panda-shaped USB-MIDI controller for Hack Club Half Life (Tier 1): 8 Kailh Choc V1 keys, EC11 encoder, rotary pot, WS2812B underglow, LOLIN S3 Mini (ESP32-S3).
